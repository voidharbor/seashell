# SeaShell App Icon

Approved 31 July 2026. Chambered nautilus spiral with a terminal cursor bar.

| File | What it is |
|---|---|
| `seashell-icon.svg` | **The master.** Edit this, then regenerate everything else. |
| `icon.icns` | macOS app icon, all 10 required slots inside. Drop into `build/`. |
| `icon-1024.png` | README, GitHub social preview, store listings |
| `icon-512.png` | Retina docs and menus |
| `icon-256.png` | General purpose |

## Installing it

The app currently ships a placeholder generated by `build/make-icon.py`. To swap in the real one:

```sh
cp icon/icon.icns build/icon.icns
npm run pack:dir
```

Nothing else references the art, so that is the whole procedure.

## How it is drawn

Not traced or freehand. The spiral is a true logarithmic curve, `r = a·e^(bθ)`, with `b` set so the radius multiplies by 2.2 each full turn over 2.5 turns. The ribbon's half-width scales as `k·r`, which makes the taper self-similar rather than eyeballed, and a `tanh` factor drives the width to a genuine point at the core instead of stopping at a stub. The ribbon is then cut into 9 chambers by transparent angular gaps.

Because the core sits at the centre and the mouth at the outside, the ribbon's colour ramp is a **radial** gradient centred on the core. That maps petrol blue to narrow and pale aqua to wide automatically, with no hand-placed stops.

Regenerate with `nautilus.py` (kept with the design session, not in this repo) or edit the SVG directly. To rebuild the `.icns` after changing the art:

```sh
mkdir icon.iconset
# 10 slots: 16, 32, 32, 64, 128, 256, 256, 512, 512, 1024
rsvg-convert -w 16 -h 16 seashell-icon.svg -o icon.iconset/icon_16x16.png   # ...etc
iconutil -c icns icon.iconset -o icon.icns
rm -rf icon.iconset
```

Flat vector throughout: no stroke, no bevel, no shadow, no gloss. Corner radius is 22.5% of width, matching the Big Sur template.

## Two things to know

**The chambers disappear at 16px.** This was chosen with that tradeoff visible: at 16px the icon reads as a spiral blob rather than a chambered shell. It resolves properly from 32px up, which covers the Dock, app switcher, and Finder icon view. Only Finder list view and small menu contexts sit below that. If it ever bothers you, the fix is optical sizing: generate the 16 and 32 slots from a reduced-chamber variant, the way SF Symbols ships different drawings per size.

**The cursor bar is a 32px-and-up element.** At the originally specified 3% height it computed to 0.48px at 16px and 0.96px at 32px, i.e. invisible in both. It was raised to 3.8% so it renders from 32px. At 16px it cannot survive without becoming a chunky slab at full size, so the small icon is the spiral alone by design.
