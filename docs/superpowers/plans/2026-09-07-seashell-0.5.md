# SeaShell 0.5 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Ship SeaShell 0.5.0: Lookout removed, find that jumps, velocity-ramped scrolling, a path double-click that works and never fails silently, a pane glow that only fires on a real bell, a restore-last-session prompt, an in-app updater, and a live file explorer.

**Architecture:** Electron 43 app, main process in `src/main` (node-pty, fs, monitor, control socket), preload in `src/preload`, React 19 renderer in `src/renderer` with xterm 6 panes. Every new rule lives in a pure module with a unit test; the wiring into xterm, Electron and React is thin and covered by a CDP smoke on a real build. Work happens on branch `0.5` in the worktree `~/Desktop/seashell-0.5`.

**Tech Stack:** TypeScript 7, Electron 43.2.0, electron-vite 5, React 19.2, @xterm/xterm 6.0.0, @xterm/addon-search 0.16.0, vitest 4 (projects `unit` = node env under `test/unit`, `dom` = happy-dom under `test/dom`), zod 4, electron-builder 26.

**Spec:** `docs/superpowers/specs/2026-09-07-seashell-0.5-design.md`

## Global Constraints

- Commit messages are ONE line, no attribution of any kind, no trailers. Example: `Remove Lookout`.
- No em-dashes anywhere in new prose, comments, UI copy, README or docs. Use commas or periods.
- NEVER kill, quit, restart or overwrite the running `/Applications/SeaShell.app`. A PreToolUse hook blocks it; do not work around the hook. Test builds run from `release/` or via `npx electron .` with `SEASHELL_USER_DATA` pointed at a scratch directory.
- `pgrep -f` cannot see SeaShell's main process. Liveness check: `ps -axo comm= | grep -q '^/Applications/SeaShell\.app/Contents/MacOS/SeaShell$'`.

- Scrollback is `20_000`, fixed. Find debounce is 120 ms. Wheel ramp ceiling is 8, decay 200 ms. Watch pool is 64 handles, debounce 250 ms. Snapshot interval is 30 s.
- Update assets must be named `SeaShell-<version>-universal.zip` and live under `https://github.com/voidharbor/seashell/releases/download/`.
- Gates before any push: `npm run typecheck && npm test && npm run build` all clean.

```js
#!/usr/bin/env node
// Drive a SeaShell instance started with --remote-debugging-port=<port>.
//   node scripts/cdp.mjs 9333 "window.__seashellTerminals.size"
//   node scripts/cdp.mjs 9333 --dblclick 400 300
//   node scripts/cdp.mjs 9333 --key Escape
// Uses Node's built-in WebSocket (Node 22+). Prints the JSON value of the expression.
const [port, ...rest] = process.argv.slice(2)
if (!port) {
  console.error('usage: cdp.mjs <port> <expression> | --dblclick x y | --key Key')
  process.exit(2)
}
const targets = await (await fetch(`http://127.0.0.1:${port}/json`)).json()
const page = targets.find((t) => t.type === 'page' && /index\.html|localhost/.test(t.url))
if (!page) {
  console.error('no page target; targets were', targets.map((t) => t.url))
  process.exit(1)
}
const ws = new WebSocket(page.webSocketDebuggerUrl)
await new Promise((r, j) => { ws.onopen = r; ws.onerror = j })
let id = 0
const pending = new Map()
ws.onmessage = (m) => {
  const msg = JSON.parse(m.data)
  if (msg.id && pending.has(msg.id)) { pending.get(msg.id)(msg); pending.delete(msg.id) }
}
const send = (method, params = {}) =>
  new Promise((r) => { const i = ++id; pending.set(i, r); ws.send(JSON.stringify({ id: i, method, params })) })

if (rest[0] === '--dblclick') {
  const x = Number(rest[1]), y = Number(rest[2])
  for (const clickCount of [1, 2]) {
    await send('Input.dispatchMouseEvent', { type: 'mousePressed', x, y, button: 'left', clickCount })
    await send('Input.dispatchMouseEvent', { type: 'mouseReleased', x, y, button: 'left', clickCount })
  }
  console.log('dblclick dispatched at', x, y)
} else if (rest[0] === '--key') {
  await send('Input.dispatchKeyEvent', { type: 'keyDown', key: rest[1] })
  await send('Input.dispatchKeyEvent', { type: 'keyUp', key: rest[1] })
  console.log('key', rest[1])
} else {
  const res = await send('Runtime.evaluate', {
    expression: rest.join(' '),
    awaitPromise: true,
    returnByValue: true,
  })
  if (res.result?.exceptionDetails) console.error(JSON.stringify(res.result.exceptionDetails, null, 2))
  console.log(JSON.stringify(res.result?.result?.value ?? null))
}
ws.close()
```

- [ ] **Step 4: implement**

Create `src/renderer/term/find-scroll.ts`:

```ts
/**
 * Where to scroll so a search match sits mid-viewport, or null when it is
 * already on screen. [pure]
 *
 * The search addon is supposed to do this itself and, on this build, does
 * not reliably: it selects the match and the viewport stays put. Owning the
 * scroll here makes the jump deterministic regardless of the addon.
 */
export function targetScrollLine(row: number, viewportY: number, rows: number): number | null {
  if (row >= viewportY && row < viewportY + rows) return null
  return Math.max(0, row - Math.floor(rows / 2))
}
```

In `terminal.ts`, replace `findNext` and `findPrevious` with:

```ts
export interface FindOptions {
  incremental: boolean
  caseSensitive: boolean
  regex: boolean
}

  find(query: string, direction: 'next' | 'prev', opts: FindOptions): boolean {
    if (this.disposed || !query) return false
    const o = {
      decorations: PaneTerminal.SEARCH_DECORATIONS,
      caseSensitive: opts.caseSensitive,
      regex: opts.regex,
      incremental: opts.incremental,
      noScroll: true,
    }
    let ok: boolean
    try {
      ok = direction === 'next' ? this.search.findNext(query, o) : this.search.findPrevious(query, o)
    } catch {
      // An unfinished regex ("[" while typing) throws inside the addon.
      return false
    }
    if (ok) this.scrollSelectionIntoView()
    return ok
  }

  private scrollSelectionIntoView(): void {
    const pos = this.term.getSelectionPosition()
    if (!pos) return
    const target = targetScrollLine(pos.start.y, this.term.buffer.active.viewportY, this.term.rows)
    if (target !== null) this.term.scrollToLine(target)
  }

  onSearchResults(cb: (r: { resultIndex: number; resultCount: number }) => void): () => void {
    const d = this.search.onDidChangeResults(cb)
    return () => d.dispose()
  }
```

```tsx
import { useEffect, useRef, useState } from 'react'
import type { FindOptions } from '../term/terminal.js'

export interface FindBarProps {
  /** Ties the bar to whatever it is searching, so switching target resets it. */
  targetKey: string
  onSearch: (query: string, direction: 'next' | 'prev', opts: FindOptions) => boolean
  onClose: () => void
  /** Bumped by the host to re-run the current query from a menu command. */
  nonce: number
  nonceDirection: 'next' | 'prev'
  /** Subscribe to result counts. Absent for targets that cannot count. */
  onResults?: (cb: (r: { resultIndex: number; resultCount: number }) => void) => () => void
  /** What the target supports. Defaults to everything. */
  capabilities?: { regex: boolean; count: boolean }
}

/** How long typing pauses before a search runs. Long enough that a burst of
 *  keystrokes over a 20,000-line buffer costs one search, not one per key. */
export const FIND_DEBOUNCE_MS = 120

/** The addon stops decorating past this many matches. */
const COUNT_CAP = 1000

export function FindBar(props: FindBarProps): React.JSX.Element {
  const caps = props.capabilities ?? { regex: true, count: true }
  const [query, setQuery] = useState('')
  const [caseSensitive, setCaseSensitive] = useState(false)
  const [regex, setRegex] = useState(false)
  const [miss, setMiss] = useState(false)
  const [count, setCount] = useState<{ index: number; total: number } | null>(null)
  const inputRef = useRef<HTMLInputElement | null>(null)
  const lastNonce = useRef(props.nonce)
  const debounce = useRef<ReturnType<typeof setTimeout> | null>(null)

  const opts = (incremental: boolean): FindOptions => ({ incremental, caseSensitive, regex })

  useEffect(() => {
    inputRef.current?.focus()
    inputRef.current?.select()
  }, [props.targetKey])

  useEffect(() => {
    if (!props.onResults) return
    return props.onResults((r) => setCount({ index: r.resultIndex, total: r.resultCount }))
  }, [props.onResults])

  // Re-issue the current query when the host asks (⌘G / ⌘⇧G).
  useEffect(() => {
    if (props.nonce === lastNonce.current) return
    lastNonce.current = props.nonce
    if (!query) return
    setMiss(!props.onSearch(query, props.nonceDirection, opts(false)))
    // Only the nonce should drive this, never a keystroke.
    // eslint-disable-next-line react-hooks/exhaustive-deps
  }, [props.nonce])

  // Search as you type, debounced. Incremental: the addon extends the current
  // match instead of jumping when the query grows by a character.
  useEffect(() => {
    if (debounce.current) clearTimeout(debounce.current)
    if (!query) {
      setMiss(false)
      setCount(null)
      return
    }
    debounce.current = setTimeout(() => {
      setMiss(!props.onSearch(query, 'next', opts(true)))
    }, FIND_DEBOUNCE_MS)
    return () => {
      if (debounce.current) clearTimeout(debounce.current)
    }
    // Toggles re-run the search too, which is what a user flipping them expects.
    // eslint-disable-next-line react-hooks/exhaustive-deps
  }, [query, caseSensitive, regex])

  const run = (direction: 'next' | 'prev'): void => {
    if (!query) return
    setMiss(!props.onSearch(query, direction, opts(false)))
  }

  const counter =
    caps.count && query
      ? `${count ? Math.max(0, count.index + 1) : 0} of ${
          count ? (count.total >= COUNT_CAP ? `${COUNT_CAP}+` : count.total) : 0
        }`
      : null

  return (
    <div className="findbar">
      <input
        ref={inputRef}
        className={'findbar__input' + (miss ? ' findbar__input--miss' : '')}
        value={query}
        placeholder="Find"
        spellCheck={false}
        onChange={(e) => {
          setQuery(e.target.value)
          setMiss(false)
        }}
        onKeyDown={(e) => {
          // Stop every key here from reaching the terminal underneath.
          e.stopPropagation()
          if (e.key === 'Enter') {
            e.preventDefault()
            run(e.shiftKey ? 'prev' : 'next')
          } else if (e.key === 'Escape') {
            e.preventDefault()
            props.onClose()
          }
        }}
      />
      {counter !== null && <span className="findbar__count">{counter}</span>}
      <button
        className={'btn findbar__toggle' + (caseSensitive ? ' findbar__toggle--on' : '')}
        title="Match case"
        aria-pressed={caseSensitive}
        onClick={() => setCaseSensitive((v) => !v)}
      >
        Aa
      </button>
      {caps.regex && (
        <button
          className={'btn findbar__toggle' + (regex ? ' findbar__toggle--on' : '')}
          title="Regular expression"
          aria-pressed={regex}
          onClick={() => setRegex((v) => !v)}
        >
          .*
        </button>
      )}
      <button className="btn findbar__btn" title="Previous (⇧⏎)" onClick={() => run('prev')}>
        ↑
      </button>
      <button className="btn findbar__btn" title="Next (⏎)" onClick={() => run('next')}>
        ↓
      </button>
      <button className="btn findbar__btn" title="Close (esc)" onClick={props.onClose}>
        ✕
      </button>
    </div>
  )
}
```

```ts
/**
 * Velocity-ramped wheel scrolling. [pure]
 *
 * Measures how fast the wheel is moving (an exponential moving average of
 * pixels per millisecond) and returns a multiplier for xterm's
 * `scrollSensitivity`. Below `onset` the multiplier is exactly 1, so a slow,
 * deliberate trackpad scroll is untouched. Above it the multiplier rises
 * linearly with `gain` and is clamped at `ceiling`. A pause longer than
 * `decayMs` resets everything, so the next scroll starts precise again.
 *
 * The constants were tuned live on a MacBook trackpad and a scroll-wheel mouse
 * (see the 0.5 spec, section 3). Change them together, not one at a time.
 */
export interface WheelRampOptions {
  /** Largest multiplier ever returned. */
  ceiling: number
  /** px/ms below which the ramp stays at 1. */
  onset: number
  /** Multiplier gained per px/ms above onset. */
  gain: number
  /** Idle gap that resets the ramp. */
  decayMs: number
  /** EMA weight of the newest sample, 0..1. */
  smoothing: number
}

export const WHEEL_RAMP_DEFAULTS: WheelRampOptions = {
  ceiling: 8,
  onset: 1.5,
  gain: 1.2,
  decayMs: 200,
  smoothing: 0.3,
}

/** Pixels per unit for WheelEvent.deltaMode 1 (line) and 2 (page). */
const LINE_PX = 16
const PAGE_PX = 400

export class WheelRamp {
  private readonly o: WheelRampOptions
  private velocity = 0
  private lastAt = -1

  constructor(opts: Partial<WheelRampOptions> = {}) {
    this.o = { ...WHEEL_RAMP_DEFAULTS, ...opts }
  }

  feed(deltaY: number, deltaMode: number, now: number): number {
    const px = Math.abs(deltaY) * (deltaMode === 1 ? LINE_PX : deltaMode === 2 ? PAGE_PX : 1)
    if (this.lastAt < 0 || now - this.lastAt > this.o.decayMs) {
      this.velocity = 0
      this.lastAt = now
      return 1
    }
    const dt = Math.max(1, now - this.lastAt)
    this.lastAt = now
    const inst = px / dt
    this.velocity += (inst - this.velocity) * this.o.smoothing
    if (this.velocity <= this.o.onset) return 1
    return Math.min(this.o.ceiling, 1 + (this.velocity - this.o.onset) * this.o.gain)
  }

  reset(): void {
    this.velocity = 0
    this.lastAt = -1
  }
}
```

`src/renderer/links/wrap-join.ts`:

```ts
/**
 * Candidates to try when a path may have been hard-wrapped by the program
 * that printed it. [pure]
 *
 * Claude Code (Ink) writes each screen row with its own newline, so xterm never
 * marks the continuation row as wrapped and the logical line is one row. The
 * only evidence a path continues is that the token reaches the right edge, or
 * starts at column 0 with a non-space run at the end of the row above.
 *
 * Order matters: the caller stats every candidate in one round trip and takes
 * the FIRST hit, so the plain token comes first and the fully joined form last.
 */
export interface JoinInput {
  candidate: string
  /** Columns the candidate occupied on its row, [startCol, endCol). */
  startCol: number
  endCol: number
  cols: number
  prevRow: string | null
  nextRow: string | null
}

const LEADING_RUN = /^[^\s]+/
const TRAILING_RUN = /[^\s]+$/

export function joinCandidates(input: JoinInput): string[] {
  const out = [input.candidate]
  const touchesRight = input.endCol >= input.cols - 1
  const touchesLeft = input.startCol === 0

  const next = touchesRight && input.nextRow ? LEADING_RUN.exec(input.nextRow)?.[0] ?? null : null
  const prev = touchesLeft && input.prevRow ? TRAILING_RUN.exec(input.prevRow)?.[0] ?? null : null

  if (next) out.push(input.candidate + next)
  if (prev) out.push(prev + input.candidate)
  if (prev && next) out.push(prev + input.candidate + next)
  return out
}

/** A path Claude Code shortened with an ellipsis: `…/renderer/app.tsx`. */
export function isSuffixCandidate(p: string): boolean {
  return p.startsWith('…/') || p.startsWith('.../')
}

/** The suffix to search for, anchored at a path-segment boundary. */
export function normaliseSuffix(p: string): string {
  const rest = p.startsWith('…/') ? p.slice(1) : p.slice(3)
  return rest.startsWith('/') ? rest : `/${rest}`
}
```

`src/main/fs/find-suffix.ts`:

```ts
import path from 'node:path'
import type { FsReadDirRequest, FsReadDirResponse } from '../../shared/ipc.js'
import { readDir as realReadDir } from './tree.js'

export interface FindBySuffixRequest {
  root: string
  /** Segment-anchored: starts with '/'. */
  suffix: string
  limit: number
}
export interface FindBySuffixResponse {
  paths: string[]
  truncated: boolean
}

/** Bounds on the walk. A reveal is user-initiated and rare; these keep a
 *  monorepo from turning one double-click into a filesystem census. */
export const MAX_DEPTH = 12
export const MAX_VISITED = 50_000

/**
 * Breadth-first over the explorer's own directory reader, so gitignored and
 * always-hidden directories are skipped exactly as the tree skips them.
 */
export async function findBySuffix(
  req: FindBySuffixRequest,
  readDirFn: (r: FsReadDirRequest) => Promise<FsReadDirResponse> = realReadDir
): Promise<FindBySuffixResponse> {
  const root = path.resolve(req.root)
  const queue: Array<{ dir: string; depth: number }> = [{ dir: root, depth: 0 }]
  const paths: string[] = []
  let visited = 0
  while (queue.length > 0) {
    const { dir, depth } = queue.shift()!
    const res = await readDirFn({ path: dir, respectGitignore: true })
    if (!res.ok) continue
    for (const e of res.entries) {
      visited += 1
      if (visited > MAX_VISITED) return { paths, truncated: true }
      const full = path.join(dir, e.name)
      if (full.endsWith(req.suffix)) {
        paths.push(full)
        if (paths.length >= req.limit) return { paths, truncated: true }
      }
      if (e.isDir && depth < MAX_DEPTH) queue.push({ dir: full, depth: depth + 1 })
    }
  }
  return { paths, truncated: false }
}
```

```ts
export interface OpenDeps {
  probe: (req: { path: string }) => Promise<FsProbeResponse>
  withDefaultApp: (req: { path: string }) => Promise<OpenPathResponse>
  revealInFinder: (req: { path: string }) => Promise<OpenPathResponse>
  onOpenInViewer: (path: string) => void
  onToast: (message: string) => void
}

/**
 * Opens a file the way the explorer does: main decides the route, the
 * renderer obeys it. `force: 'os'` skips the route and hands the file to the
 * default app (Cmd+Opt+double-click on a path).
 */
export async function openPath(fullPath: string, deps: OpenDeps, force?: 'os'): Promise<void> {
  const probe = await deps.probe({ path: fullPath })
  if (!probe.exists) {
    deps.onToast('File no longer exists')
    return
  }
  if (probe.isDir) return
  const route = force ?? probe.route
  switch (route) {
    case 'viewer':
      deps.onOpenInViewer(fullPath)
      return
    case 'os': {
      const res = await deps.withDefaultApp({ path: fullPath })
      if (!res.ok && res.error === 'refused-executable') {
        deps.onToast('That file is executable, revealed in Finder instead')
      } else if (!res.ok) {
        deps.onToast(`Could not open: ${res.error ?? 'unknown error'}`)
      }
      return
    }
    case 'too-large':
      deps.onToast('Too large to preview, opening with the default app')
      await deps.withDefaultApp({ path: fullPath })
      return
    case 'binary':
    case 'reveal':
      await deps.revealInFinder({ path: fullPath })
      return
  }
}
```

```ts
import type { PaneActivity } from '../../shared/ipc.js'

/**
 * Whether a pane should be asking for your eyes.
 *
 * `waiting` is an EVENT now, not an inference. It is set by the reducer when
 * the pane's program rings the terminal bell (`pane.bell`) while the pane is
 * unfocused and its foreground is not the bare shell. Claude Code rings on a
 * permission prompt and on an idle prompt after a turn, once its notification
 * channel is the terminal bell; other programs ring when they mean it. The
 * old rule, twenty seconds of low CPU, was the resting state of every idle
 * agent, so every finished pane glowed like one asking a question.
 *
 * This function only carries a set `waiting` forward and decides `done`:
 *  - focused clears everything (looking at it is acknowledging it),
 *  - a program that goes back to work (BUSY) has nothing to ask yet,
 *  - returning to the shell prompt after running something pulses `done`.
 */
export type Attention = 'waiting' | 'done' | null

/** How long a "finished" pulse runs before it stops asking. */
export const DONE_ATTENTION_MS = 9000

export interface AttentionInput {
  previous: PaneActivity | undefined
  next: PaneActivity
  current: Attention
  focused: boolean
}

export function nextAttention(input: AttentionInput): Attention {
  if (input.focused) return null
  if (input.next === 'BUSY') return null
  if (input.next === 'PROMPT') {
    if (input.previous === 'BUSY' || input.previous === 'WAITING') return 'done'
    return input.current === 'done' ? 'done' : null
  }
  // WAITING: carry a bell-set waiting forward; never create one here.
  return input.current === 'waiting' ? 'waiting' : input.current === 'done' ? 'done' : null
}

/** True once a finished pulse has run long enough to stop. */
export function doneExpired(setAt: number | undefined, now: number): boolean {
  if (setAt === undefined) return false
  return now - setAt >= DONE_ATTENTION_MS
}
```

```ts
import fs from 'node:fs/promises'
import path from 'node:path'
import type { SavedTab } from '../../shared/ipc.js'
import { isValidProject } from './store.js'

const FILE = 'last-session.json'
export const SCHEMA_VERSION = 1

export interface LastSession {
  schemaVersion: typeof SCHEMA_VERSION
  savedAt: string
  tabs: SavedTab[]
}

/**
 * The window as it last stood, so a relaunch can offer it back. Same tab shape
 * as a project, validated by the same rule, written atomically so a crash
 * mid-write leaves the previous snapshot rather than half of a new one.
 */
export async function saveLastSession(tabs: SavedTab[], dir: string): Promise<void> {
  const file = path.join(dir, FILE)
  const tmp = `${file}.tmp`
  const body: LastSession = { schemaVersion: SCHEMA_VERSION, savedAt: new Date().toISOString(), tabs }
  await fs.writeFile(tmp, JSON.stringify(body, null, 2))
  await fs.rename(tmp, file)
}

export async function loadLastSession(dir: string): Promise<LastSession | null> {
  try {
    const raw = JSON.parse(await fs.readFile(path.join(dir, FILE), 'utf8')) as Partial<LastSession>
    if (raw?.schemaVersion !== SCHEMA_VERSION || typeof raw.savedAt !== 'string') return null
    if (!isValidProject({ id: 'last', name: 'last', savedAt: raw.savedAt, tabs: raw.tabs })) return null
    return { schemaVersion: SCHEMA_VERSION, savedAt: raw.savedAt, tabs: raw.tabs as SavedTab[] }
  } catch {
    return null
  }
}

export async function clearLastSession(dir: string): Promise<void> {
  await fs.rm(path.join(dir, FILE), { force: true })
}
```

```ts
export const RELEASE_ORIGIN = 'https://github.com/voidharbor/seashell/releases/download/'

export interface ReleaseInfo {
  version: string
  zipUrl: string
  zipBytes: number
  pageUrl: string
}

const VERSION_RE = /^(\d+)\.(\d+)\.(\d+)$/

function triple(v: string): [number, number, number] | null {
  const m = VERSION_RE.exec(v)
  return m ? [Number(m[1]), Number(m[2]), Number(m[3])] : null
}

/** Strictly newer, numerically. Anything unparseable is never newer. */
export function isNewer(candidate: string, current: string): boolean {
  const a = triple(candidate)
  const b = triple(current)
  if (!a || !b) return false
  for (let i = 0; i < 3; i += 1) {
    if (a[i]! !== b[i]!) return a[i]! > b[i]!
  }
  return false
}

/**
 * Reads GitHub's releases/latest JSON down to the one asset the updater may
 * fetch: the universal zip, named exactly for the version, hosted on the
 * release download origin. Anything else is null, which means "no update".
 */
export function parseRelease(json: unknown): ReleaseInfo | null {
  if (typeof json !== 'object' || json === null) return null
  const r = json as { tag_name?: unknown; html_url?: unknown; assets?: unknown }
  if (typeof r.tag_name !== 'string' || !r.tag_name.startsWith('v')) return null
  const version = r.tag_name.slice(1)
  if (!VERSION_RE.test(version)) return null
  if (!Array.isArray(r.assets)) return null
  const want = `SeaShell-${version}-universal.zip`
  const asset = r.assets.find(
    (a): a is { name: string; size: number; browser_download_url: string } =>
      typeof a === 'object' && a !== null && (a as { name?: unknown }).name === want
  )
  if (!asset || typeof asset.size !== 'number' || typeof asset.browser_download_url !== 'string') return null
  if (!asset.browser_download_url.startsWith(RELEASE_ORIGIN)) return null
  const pageUrl = typeof r.html_url === 'string' ? r.html_url : `https://github.com/voidharbor/seashell/releases/tag/v${version}`
  return { version, zipUrl: asset.browser_download_url, zipBytes: asset.size, pageUrl }
}
```

```ts
export interface InstallScriptInput {
  pid: number
  zipPath: string
  stagingDir: string
  appPath: string
  expectedVersion: string
  logPath: string

/**
 * The swap, as a shell script run detached after the app quits. Every step
 * that can fail leaves the current install where it was: the old bundle is
 * moved aside, not deleted, until the new one is in place.
 */
export function buildInstallScript(o: InstallScriptInput): string {
  return [
    '#!/bin/sh',
    'set -u',
    `LOG="${o.logPath}"`,
    'exec >>"$LOG" 2>&1',
    'echo "install start $(date)"',
    'i=0',
    `while kill -0 ${o.pid} 2>/dev/null; do i=$((i+1)); if [ $i -ge 300 ]; then echo "app did not exit"; exit 1; fi; sleep 0.1; done`,
    `STAGE="${o.stagingDir}"`,
    `ZIP="${o.zipPath}"`,
    `APP="${o.appPath}"`,
    'rm -rf "$STAGE"; mkdir -p "$STAGE"',
    'ditto -x -k "$ZIP" "$STAGE" || { echo "unzip failed"; exit 1; }',
    'NEW="$STAGE/SeaShell.app"',
    `V=$(/usr/libexec/PlistBuddy -c 'Print :CFBundleShortVersionString' "$NEW/Contents/Info.plist" 2>/dev/null)`,
    `if [ "$V" != "${o.expectedVersion}" ]; then echo "version mismatch: $V"; exit 1; fi`,
    'OLD="$STAGE/previous.app"',
    'rm -rf "$OLD"',
    'mv "$APP" "$OLD" || { echo "could not move old app"; exit 1; }',
    'mv "$NEW" "$APP" || { mv "$OLD" "$APP"; echo "could not move new app"; exit 1; }',
    'xattr -dr com.apple.quarantine "$APP" 2>/dev/null',
    'rm -rf "$OLD" "$ZIP"',
    'open -a "$APP"',
    'echo "install done $(date)"',
    '',
  ].join('\n')
}
```

```ts
import { spawn } from 'node:child_process'
import fs from 'node:fs'
import fsp from 'node:fs/promises'
import path from 'node:path'
import { net } from 'electron'
import type { UpdateState } from '../../shared/ipc.js'
import { isNewer, parseRelease, type ReleaseInfo } from './check.js'
import { buildInstallScript } from './install-script.js'

export interface UpdaterDeps {
  currentVersion: string
  isPackaged: boolean
  /** app.getPath('exe') */
  exePath: string
  userData: string
  platform: NodeJS.Platform
  send: (state: UpdateState) => void
  /** The app's own pid, for the install script's wait. */
  pid: number
  quit: () => void
}

/** Both overridable for smoke tests only: a file:// release JSON and a scratch
 *  copy of the bundle, so a test never touches GitHub or the installed app. */
const API = process.env.SEASHELL_UPDATE_API ?? 'https://api.github.com/repos/voidharbor/seashell/releases/latest'
const INSTALLED_APP = process.env.SEASHELL_UPDATE_APP_PATH ?? '/Applications/SeaShell.app'
const TIMEOUT_MS = 5000

export class Updater {
  private release: ReleaseInfo | null = null
  private zipPath: string | null = null
  private state: UpdateState = { phase: 'idle' }

  constructor(private readonly d: UpdaterDeps) {}

  private set(s: UpdateState): void {
    this.state = s
    this.d.send(s)
  }

  /** One check per launch. Silent on every failure: an updater must never nag. */
  async start(): Promise<void> {
    if (!this.d.isPackaged || process.env.SEASHELL_NO_UPDATE_CHECK) return
    try {
      const ctl = new AbortController()
      const t = setTimeout(() => ctl.abort(), TIMEOUT_MS)
      const res = await net.fetch(API, { headers: { accept: 'application/vnd.github+json' }, signal: ctl.signal })
      clearTimeout(t)
      if (!res.ok) return
      const info = parseRelease(await res.json())
      if (!info || !isNewer(info.version, this.d.currentVersion)) return
      this.release = info
      const canInstall = this.d.platform === 'darwin' && this.d.exePath.startsWith(INSTALLED_APP + '/')
      this.set({ phase: 'available', version: info.version, pageUrl: info.pageUrl, canInstall })
    } catch {
      /* offline, rate-limited, whatever: say nothing */
    }
  }

  async download(): Promise<void> {
    const info = this.release
    if (!info || this.state.phase !== 'available') return
    const dir = path.join(this.d.userData, 'updates')
    await fsp.mkdir(dir, { recursive: true })
    const target = path.join(dir, `SeaShell-${info.version}-universal.zip`)
    this.set({ phase: 'downloading', version: info.version, received: 0, total: info.zipBytes })
    try {
      const res = await net.fetch(info.zipUrl)
      if (!res.ok || !res.body) throw new Error(`download failed (${res.status})`)
      const out = fs.createWriteStream(target)
      const reader = res.body.getReader()
      let received = 0
      for (;;) {
        const { done, value } = await reader.read()
        if (done) break
        received += value.byteLength
        if (!out.write(value)) await new Promise<void>((r) => out.once('drain', () => r()))
        this.set({ phase: 'downloading', version: info.version, received, total: info.zipBytes })
      }
      await new Promise<void>((r, j) => out.end((e?: Error | null) => (e ? j(e) : r())))
      const size = (await fsp.stat(target)).size
      if (size !== info.zipBytes) throw new Error(`size mismatch: got ${size}, expected ${info.zipBytes}`)
      this.zipPath = target
      this.set({ phase: 'ready', version: info.version })
    } catch (e) {
      await fsp.rm(target, { force: true })
      this.set({ phase: 'error', version: info.version, message: e instanceof Error ? e.message : String(e) })
    }
  }

  async install(): Promise<void> {
    const info = this.release
    if (!info || !this.zipPath || this.state.phase !== 'ready') return
    const dir = path.join(this.d.userData, 'updates')
    const script = path.join(dir, 'install.sh')
    await fsp.writeFile(
      script,
      buildInstallScript({
        pid: this.d.pid,
        zipPath: this.zipPath,
        stagingDir: path.join(dir, 'staging'),
        appPath: INSTALLED_APP,
        expectedVersion: info.version,
        logPath: path.join(dir, 'install.log'),
      }),
      { mode: 0o755 }
    )
    const child = spawn('/bin/sh', [script], { detached: true, stdio: 'ignore' })
    child.unref()
    this.d.quit()
  }
}
```

```ts
/** Which directories to drop so the pool is back under `max`, oldest touch first. [pure] */
export function pickEvictions(entries: Array<{ dir: string; lastTouch: number }>, max: number): string[] {
  const over = entries.length - max
  if (over <= 0) return []
  return [...entries]
    .sort((a, b) => a.lastTouch - b.lastTouch)
    .slice(0, over)
    .map((e) => e.dir)
}

}
```

```ts
import { isWatchable, pickEvictions } from './watcher-pool.js'

export interface DirWatcherDeps {
  emit: (dir: string) => void
  lost: (dir: string) => void
  max?: number
  debounceMs?: number
  now?: () => number
}

interface Entry {
  watcher: fs.FSWatcher
  lastTouch: number
  timer: ReturnType<typeof setTimeout> | null
}

/**
 * One non-recursive fs.watch per expanded directory, capped, debounced.
 *
 * macOS delivers these through FSEvents via libuv; a handle per directory is
 * cheap but not free, so the pool evicts the least recently rendered when it
 * is full. A dropped watch is reported, never silently absent, so the explorer
 * can fall back to click-to-refresh for that directory.
 */
export class DirWatcher {
  private readonly entries = new Map<string, Entry>()
  private readonly max: number
  private readonly debounceMs: number
  private readonly now: () => number

  constructor(private readonly d: DirWatcherDeps) {
    this.max = d.max ?? 64
    this.debounceMs = d.debounceMs ?? 250
    this.now = d.now ?? Date.now
  }

  subscribe(dir: string): void {
    if (this.entries.has(dir) || !isWatchable(dir)) return
    let watcher: fs.FSWatcher
    try {
      watcher = fs.watch(dir, { persistent: false })
    } catch {
      this.d.lost(dir)
      return
    }
    const entry: Entry = { watcher, lastTouch: this.now(), timer: null }
    watcher.on('change', () => this.schedule(dir, entry))
    watcher.on('error', () => {
      this.drop(dir)
      this.d.lost(dir)
    })
    this.entries.set(dir, entry)
    for (const victim of pickEvictions([...this.entries].map(([k, v]) => ({ dir: k, lastTouch: v.lastTouch })), this.max)) {
      this.drop(victim)
      this.d.lost(victim)
    }
  }

  unsubscribe(dir: string): void {
    this.drop(dir)
  }

  touch(dir: string): void {
    const e = this.entries.get(dir)
    if (e) e.lastTouch = this.now()
  }

  has(dir: string): boolean {
    return this.entries.has(dir)
  }

  size(): number {
    return this.entries.size
  }

  close(): void {
    for (const dir of [...this.entries.keys()]) this.drop(dir)
  }

  private schedule(dir: string, e: Entry): void {
    if (e.timer) return
    e.timer = setTimeout(() => {
      e.timer = null
      if (this.entries.has(dir)) this.d.emit(dir)
    }, this.debounceMs)
  }

  private drop(dir: string): void {
    const e = this.entries.get(dir)
    if (!e) return
    if (e.timer) clearTimeout(e.timer)
    e.watcher.close()
    this.entries.delete(dir)
  }
}
```
